# QA physique — non réalisée pendant ce chantier

Utiliser deux comptes KFFR distincts, un iPhone sous Expo Go SDK 57 et un PC connecté au web existant. Ces essais humains sont volontaires ; aucune partie réelle n’a été créée par les suites automatisées.

- [ ] Vérifier la branche/QR du Metro utilisé ; compte existant, pseudo et Solo encore corrects.
- [ ] PC crée → iPhone trouve le code ; puis iPhone crée → PC rejoint.
- [ ] Rejoindre une place différente ; voir les mêmes noms, hôte, présence et prêts sur les deux appareils.
- [ ] Changer de place, quitter une place, rejoindre simultanément la même place ; un seul gagnant, erreur claire pour l’autre.
- [ ] Essayer une table complète, un code invalide et une invitation expirée.
- [ ] Inviter un ami, accepter puis prendre une place ; refuser une autre invitation.
- [ ] Prêts, lancement par l’hôte, bots sur les places libres ; répéter avec quatre humains.
- [ ] Enchère PC reçue sur iPhone ; puis enchère iPhone reçue sur PC. Couleurs, SA/TA, Capot/Générale, Coinche/Surcoinche suivant les règles configurées.
- [ ] Jouer depuis chacune des quatre places : moi en bas, partenaire en face, bonnes mains, plis et équipes dans le HUD.
- [ ] Vérifier la réaction immédiate d’une carte, l’absence de spinner, les doubles appuis, le refus d’une carte illégale et les versions après actions simultanées.
- [ ] Réseau interrompu pendant une pose, réponse incertaine : aucune répétition automatique ; GET à la reprise et main cohérente.
- [ ] Arrière-plan/verrouillage/appel entrant puis retour : main masquée durant vérification, même table rechargée, pas de double subscription.
- [ ] Hôte absent/transféré/récupéré ; bot temporaire sur un absent, puis retour humain.
- [ ] Timer de tour, bots, collecte auto/manuelle, dernier pli, manche suivante.
- [ ] Terminer une vraie partie : mêmes scores/résultats, Elo/XP/historique serveur cohérents ; revanche puis lobby.
- [ ] Forfait confirmé : bon vainqueur, hôte et résultat communs.
- [ ] Retour accueil puis rouvrir la dernière table locale ; changement de compte sans retrouver la main/table privée du précédent.
- [ ] iPhone paysage gauche/droite, Dynamic Island, petit paysage, portrait et mouvement réduit ; grandes polices et VoiceOver.
- [ ] Son, musique, volume, mise en sourdine au blur/arrière-plan et reprise volontaire.
- [ ] Rejouer une partie Solo : graphismes, cartes immédiates et bots inchangés.

Consigner modèle/iOS/version Expo Go, SHA mobile, comptes de test, réseau, résultat et éventuels clips/captures pour chaque réserve. Ne pas cocher sans observation physique.
